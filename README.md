# Hello World Website

A minimal, modern website containing a single centered "Hello World" button with smooth animations and click interactions.

## Project Structure

```
hello-world-website/
├── index.html       # Main webpage structure
├── style.css        # Modern centered styles & button animations
├── script.js        # Button click handler
└── README.md        # Project documentation
```

## How to View

1. **Directly in Browser**:
   Double-click `index.html` or open it with your favorite web browser (Chrome, Edge, Firefox).

2. **Using a Local Server** (Optional):
   - With Python:
     ```bash
     python -m http.server 3000
     ```
   - With Node.js (`npx serve`):
     ```bash
     npx serve .
     ```
