# University Student & Alumni ERP Portal

A modern web application featuring interactive Excel spreadsheets for 500 current students, a master directory of 1,000 alumni (including all featured Happy Exit Graduates), and a convocation photo gallery—all seamlessly integrated on a single page.

## Key Features

- **Navigation Buttons**:
  - **🎓 Student Details**: Opens the master student ERP spreadsheet (500 records).
  - **💼 Alumni Details**: Opens the master alumni career directory (**1,000 records**).
- **1,000 Alumni Directory**:
  - **Featured Happy Exit Graduates Included**: Aarav Sharma (*Google*), Priya Iyer (*Microsoft*), Rohan Verma (*AWS*), Sneha Kulkarni (*Tesla*), Vikram Singh (*Boeing*), Ananya Patel (*Meta AI*) are proudly listed right at the top of the Alumni sheet with a `★ Grad 2024` badge.
  - Plus 994 additional alumni across all 5 engineering departments.
  - Fields: Alumni ID, Alumni Name, Department, Current Designation, and Monthly Salary.
  - Dedicated multi-criteria filter: Filter by Alumni Name, Department, and Designation.
- **Student ERP Spreadsheet**:
  - Master single-sheet view of 500 records across 5 engineering departments.
  - Multi-criteria filter: Filter by Roll No, Name, and Department.
- **🎓 Happy Exit Students Gallery**:
  - Highlighting graduating students and alumni stepping into top global tech companies.
  - Displays avatar portraits, convocation moments, batch year, placed company, and inspiring quotes.
- **Export to CSV**:
  - One-click export for both the 500 Student and 1,000 Alumni datasets into Excel-compatible `.csv` files.
